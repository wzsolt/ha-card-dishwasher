# Changelog

## [0.2.0]

- Recover the cycle programme and initial duration from Recorder and read the countdown directly from the appliance.
- Discover entity mappings from the selected device or state sensor, and pre-fill the editor when one dishwasher is recognized.
- Add a two-line dashboard example for `kitchen_dishwasher` and retain compatibility with existing template sensor mappings.

## [0.1.0]

- Add the standalone AEG Dishwasher Card with Hungarian and English labels and a visual editor.
- Show the saved programme, Eco indicator, cycle count, estimated progress, timing, phase, door and alerts.
- Bundle the open and closed illustrations and the running, delayed and finished animations with reduced-motion support.
- Include sample Home Assistant templates and Dashboard installation through HACS.
